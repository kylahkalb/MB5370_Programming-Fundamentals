## About This Repository

This repository documents my practical coursework for the Programming Fundamentals module of MB5370: Techniques in Marine Science 1 at James Cook University.

Throughout this module, I developed foundational skills in R programming, data visualisation, reproducible research, and version control, with applications relevant to marine science.

## Workshop Overview

**Workshop 1 — Introduction to R**

Exploring R syntax, arithmetic, objects, functions, data types, data structures, and project organisation.

**Workshop 2 — Data Visualisation with ggplot2**

Creating and customising figures using aesthetic mappings, facets, statistical transformations, and multiple plot layers.

**Workshop 3 — Reproducible Research**

Using Git and GitHub to manage version control, organise projects, and support reproducible scientific workflows.

**Workshop 4 — The Developer's Toolbox & AI**

Exploring AI-assisted programming, biological data visualisation, and environmental classification using tidyverse functions.

## Repository Structure

- `code/` — R scripts and R Markdown workshop exercises.
- `data/` — Data files used in practical activities.
- `docs/` — Quarto documents and rendered reports.
- `output/` — Generated figures and analysis outputs.
