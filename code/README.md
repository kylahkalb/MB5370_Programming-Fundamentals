# Workshop Scripts

This folder contains R scripts and R Markdown documents developed during the **Programming Fundamentals** module of MB5370: Techniques in Marine Science 1 at James Cook University.

## Contents

- **Workshop01.R** — Introduction to R, basic arithmetic, object assignment, and plotting.
- **Workshop01_Fundamentals.R** — R syntax, functions, data types, data structures, and project organisation.
- **Workshop02_Visualisation.R** — Data visualisation using ggplot2, including aesthetic mappings, facets, and statistical transformations.
- **Workshop03.R** — Reproducible research, Git, GitHub, and version control.
- **Workshop04.Rmd** — The Developer's Toolbox & AI, including penguin data visualisations and environmental classification using `case_when()`.

These files document my practical exercises and development of foundational R programming skills.
